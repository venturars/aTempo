# Instrucciones para construir aTempo

La constitución está en `README.md`. Decide el producto. La sección 15 es el sistema visual. No cambia el resto.

Antes de una pantalla, lee esa sección: los temas, los colores de estado y los principios de interfaz. Luego lee `packages/design-system/rules.md` y `packages/design-system/theme.css`. Los patrones para copiar están en `packages/design-system/reference/guia.html`, y se abre en el navegador para mirarla. No inventes otro sistema visual. Si ya existe un componente compartido para una pieza, úsalo en lugar de escribir las clases.

El CSS se importa una vez, como dice `packages/design-system/README.md`.
