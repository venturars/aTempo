# Instrucciones para construir aTempo

La constitución está en `README.md`. Decide el producto. La sección 15 es el sistema visual. No cambia el resto.

Antes de una pantalla, lee esa sección: los temas, los colores de estado y los principios de interfaz. Luego lee `packages/design-system/rules.md` y `packages/design-system/theme.css`. Ahí está cómo se ve y cómo se escribe, para cualquier feature. No inventes otro sistema visual.

El CSS se importa una vez, como dice `packages/design-system/README.md`.
