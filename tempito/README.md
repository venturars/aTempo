# Tempito — prototipo visual

Bocetos de interfaz para revisar con el grupo y con Ventura. No es la aplicación.

Abrir `index.html` en el navegador. Las cuatro pantallas se recorren con la barra inferior y con Perfil.

- Inicio
- Evolución
- Misiones
- Personalización

Datos de ejemplo: Lucía, nivel 3, 240 / 300 XP, ánimo Curioso.

En Personalización (y en el inventario de Inicio) se pueden poner y quitar gafas, sombrero y bufanda. Mochila y bosque están bloqueados. No se guarda nada.

La mascota es `assets/mascot/tempito.jpg`. No sustituirla por otro personaje.
