# Principios

Siguen la [guía de Apple](https://developer.apple.com/design/human-interface-guidelines). El texto es nuestro.

## Hacer

- Un control se reconoce por lo que es: un botón es `button`, un enlace es `a`, un campo es `input`.
- La misma acción usa la misma clase y el mismo verbo en todas partes.
- Se actúa sobre el elemento, no en un sitio lejano de la pantalla.
- Cada acción deja una respuesta visible.
- Se puede cerrar o deshacer. Nada se confirma solo.

## No hacer

- Un `div` con un clic en lugar de un control.
- La misma acción con dos aspectos distintos.
- Cerrar o borrar sin una respuesta que se vea.
