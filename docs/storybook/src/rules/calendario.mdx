# Calendario

El calendario lo pinta React Day Picker 9.14.0, la misma versión que `desktop/`. La historia está en Entrada/Calendar.

## Hacer

- Usar el calendario para elegir un intervalo de fechas (`mode="range"`) o varias fechas sueltas (`mode="multiple"`).
- Ponerle la clase `react-day-picker` de daisyUI y el `locale` del idioma de la aplicación, de `react-day-picker/locale`. En `desktop/` lo da `calendarLocale()`, de `language/format.ts`. La historia usa `es`, porque la guía está en español.
- Importar `react-day-picker/style.css`. Los colores salen del tema: las variables `--rdp-*` usan `primary` y los fondos `base`.
- Mantener los nombres de los días de la semana (`.rdp-weekday`) a 12px, con peso 500, como define el sistema compartido.

```tsx
<DayPicker className="react-day-picker" locale={calendarLocale()} mode="range" selected={range} onSelect={setRange} />
```

## No hacer

- Escribir a mano un color del calendario.
