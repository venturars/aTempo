# Accesibilidad

Siguen la [guía de Apple](https://developer.apple.com/design/human-interface-guidelines). El texto es nuestro.

## Hacer

- El foco se ve. El tema dibuja el anillo con `outline` en `:focus-visible`.
- El nombre del control se ve. El placeholder no es el nombre.
- El color no va solo: el estado lleva texto.
- Con puntero grueso, campo y botón llegan a 44 px.

## No hacer

- Quitar el anillo de foco.
- Un control que solo se entiende por el color.
- Un icono solo, sin un nombre visible.
