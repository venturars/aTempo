# Layout

Siguen la [guía de Apple](https://developer.apple.com/design/human-interface-guidelines). El texto es nuestro.

## Hacer

- Lo importante va arriba y al inicio de la lectura.
- Lo relacionado se agrupa. Lo que no lo está, se separa.
- En cada zona hay una acción primaria: `btn btn-primary`.
- No se muestra todo a la vez si se puede revelar al pedirlo.

## No hacer

- Dos botones `btn-primary` en la misma zona.
- Mezclar en el mismo grupo cosas que no tienen relación.
