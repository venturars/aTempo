# Escritura

Siguen la [guía de Apple](https://developer.apple.com/design/human-interface-guidelines). El texto es nuestro.

## Hacer

- Español, de tú, en frases cortas.
- Un botón es un verbo: Guardar, Cerrar, Seguir.
- Un error dice qué pasa y cómo seguir, en una línea. Ejemplo: «El correo no tiene una forma válida.»

## No hacer

- Un subtítulo si la etiqueta ya lo dice.
- Signos de exclamación para animar.
- Una frase que no hace falta para entender la pantalla.
